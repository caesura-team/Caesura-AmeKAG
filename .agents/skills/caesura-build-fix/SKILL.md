# Caesura 构建错误定位
读取真实命令、构建配置、工具链、工作目录与首次有效错误。先区分源码错误、缺依赖、旧产物路径、资源CWD、环境问题和并行构建冲突。
- 复用当前 CMake preset、生产静态库和现有模块接口；不为过编译改变架构。
- include 大小写与git索引一致，禁止跨模块实现头依赖和绝对include。
- Lua新依赖必须在需要的沙箱/索引/隔离夹具中真实注册，不能通过跳过套件隐藏失败。
- 一次修最小根因，再运行受影响构建/测试；共享构建目录由主代理控制。
- 不通过删除用例、关闭required依赖或吞掉退出码得到绿色。
若原命令本身选错产物，修正执行入口并保留原失败证据。结果说明修复、实际验证命令与尚未具备的环境。

详细执行约定见 [Codex 工作流](../../../docs/team/codex-workflow.md)。
