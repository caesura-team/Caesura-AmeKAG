# Caesura 安全边界
保持用户授权范围，读取当前接口、信任来源和输入数据流；不因使用本技能扩大成无关整仓安全扫描。
重点随补丁选择：CARC长度/加解密/签名与发布者信任、路径规范/越界、存档失败旧数据保留、Lua沙箱、RPC授权/超时终态、异步owner过期和敏感日志。
- 先确认输入确实能到达被测路径，区分静态疑点与已复现问题。
- 用最小正负样本证明接受合法输入、拒绝恶意或坏输入；不泄露密钥、账号内容或凭据值。
- 可复用已连接安全插件，但不因插件缺失无法做本地代码/测试分析；遵循实际工具和授权。
- 修复不改变无关模块边界；严重问题需明确反馈并优先修复。外部服务写入、凭据轮换和权限变更按独立授权处理。
提交前检查新增敏感内容，结果给触发条件、影响、修复证据和剩余条件，不能把猜测写成已验证漏洞。

详细执行约定见 [Codex 工作流](../../../docs/team/codex-workflow.md)。
