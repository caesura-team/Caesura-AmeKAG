# Caesura 有界重构
先建立现有行为、调用者与使用边界，再决定删除或提取。不要因静态搜索未命中就认定Lua动态入口、生成注册或平台实现无用。
- 通过源码、CMake目标、Lua preload、Web索引和运行回归核实依赖。
- 沿用API/BackendRegistry/组合根约束，优先小范围共享实现；避免引入新的通用框架。
- 每次修改围绕一个有证据的问题，保留兼容合同并以真实测试比较行为。
- 删除前核对Git状态和来源，保留不属于本任务的修改；用户授权清理agent痕迹时只删除确认的运行/冗余约束，保留源码、必要技能和验证夹具。
- 性能优化先有可比较测量和预算，不在回归失败后调整阈值。
完成后报告删除/整合范围、相关测试及未改的外部条件，不以代码行数减少作为唯一成效。

详细执行约定见 [Codex 工作流](../../../docs/team/codex-workflow.md)。
