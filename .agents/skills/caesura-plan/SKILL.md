# Caesura 实施规划
先读取适用 AGENTS.md、docs/plans/README.md、当前执行记录和相关源码。保留用户已有修改，区分当前合同和历史排期。
- 明确用户要求、可见行为、所有权/取消/失败边界，以及完成每项要求的实际证据。
- 沿用模块 API、BackendRegistry 和组合根；需要改接口时列出实现类、注册及组合根接线。
- 依赖排序，分解成可整合的工作，不把全局目标缩成当前最容易通过的切片。
- 只有有独立有用任务时才派发子代理，指定文件范围；共享构建由主代理统一运行。
- 设计先复现的回归和负控制，说明预备失败保留旧状态、提交失败安全停止等合同。
- 有明确实施授权就继续，不因选择此技能重新要求用户批准同一计划。真实产品歧义才提出必要问题，同时推进独立工作。
输出具体文件/依赖/风险/验证计划。不要为制造计划而另建系统或修改源码。

详细执行约定见 [Codex 工作流](../../../docs/team/codex-workflow.md)。
