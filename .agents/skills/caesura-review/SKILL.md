# Caesura 代码审查
确认 .git 后查看所审 diff 与基线，不覆盖用户修改。主代理可使用此流程自检；有可独立进行的审查任务时交给未编写该补丁的子代理。
重点检查：
- 公共 I* 接口、第三方句柄隔离、BackendRegistry访问与组合根所有权。
- 取消/回调代次、并发数据生命周期、失败后继续能力和资源准确释放。
- 存档/回滚/缓存实际语义，旧状态是否被未来值污染，准备/提交边界是否清楚。
- 外部输入、路径、归档长度和RPC授权等补丁实际触及的安全边界。
- 回归是否经过真实代码路径、有负控制和正控制；证据是否匹配当前代码及配置。
只报告可行动且有依据的问题，给出文件位置、触发条件、影响和修复方向。按优先级排序；没有问题时说明审查范围和残余未测项。代码变更后审查，后续仅复核实质增量或已指出问题的修复，不重复整仓泛扫。

详细执行约定见 [Codex 工作流](../../../docs/team/codex-workflow.md)。
