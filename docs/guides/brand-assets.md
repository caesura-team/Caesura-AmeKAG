# Caesura 品牌标志

品牌核心是 **Next Generation of Visual Novel**：面向下一代视觉小说的可编程叙事、动态场景与跨平台创作。

引擎标志使用开放的 C 形结构和分岔的青色场景平面，体现扩展能力与向前发展的交互叙事。组织标志保留同一几何语言，使用连续的场景平面与深色底，便于与引擎图标区分。
